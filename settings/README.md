# Каталог настроек

Лучшие настройки для проектов. Каждая настройка — отдельная карточка-`.md` с описанием, что делает и как поставить.

При создании нового проекта пройдись по этому списку и реши, какие настройки добавить.

## Настройки

| Настройка | Что делает | Область |
|---|---|---|
| [notification-sound.md](notification-sound.md) | Звуковой сигнал, когда Claude ждёт твоего ответа | Глобально (все проекты) |

## Как добавлять новую настройку

1. Создай файл `settings/<имя>.md` по образцу существующих карточек.
2. Добавь строку в таблицу выше.
3. Структура карточки: **что делает → зачем → как устроено → установка → проверка → настройка под себя**.
