# general-project-settings

Каталог лучших настроек для проектов Claude Code. Собираем настройки карточками, чтобы при
старте нового проекта пройтись по списку и выбрать нужное.

## Быстрый старт
1. Открой [settings/README.md](settings/README.md) — это индекс всех настроек.
2. Пройдись по карточкам и реши, какие настройки добавить в текущий проект.
3. Каждая карточка содержит готовые блоки для копирования и проверку.

## Что внутри
- [settings/](settings/) — карточки настроек (по одной на настройку) + индекс.
- [project-starter.md](project-starter.md) — базовый свод правил работы для новых проектов.
- `MEMORY.md`, `ARCHITECTURE.md` — журнал и карта проекта (контекст для сессий).

## Воркфлоу
- **`git load`** (начало сессии): читаем `MEMORY.md` и ключевые файлы, кратко смотрим, где остановились.
- **`git save`** (конец блока работы): обновляем `MEMORY.md`/changelog, коммитим; push — по команде.

Подробные соглашения — в [project-starter.md](project-starter.md), раздел 6.

## Добавить новую настройку
1. Создай `settings/<имя>.md` по образцу существующих карточек.
2. Добавь строку в таблицу в [settings/README.md](settings/README.md).
3. Структура карточки: что делает → зачем → как устроено → установка → проверка → настройка под себя.
